# Notes

个人研究笔记目录。线上入口：<https://lsyhahaha.github.io/notes/>。

## 新增笔记

1. 在 `_posts/` 新增 `YYYY-MM-DD-slug.md`，文件名使用小写英文和连字符。
2. 复制现有笔记的 YAML Front Matter，填写标题、来源、证据类型、主题、摘要和固定链接。
3. 正文使用 Markdown；只有摘要框、对比表等既有特殊版式需要少量语义化 HTML。
4. `index.html` 通过 Liquid 自动读取笔记，不手工复制卡片。
5. 明确标注证据类型：官方材料、公开源码分析、个人推论或尚未验证。
6. 外部结论链接到原始来源，不把厂商案例直接表述为普遍事实。
