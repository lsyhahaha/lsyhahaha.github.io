# Notes

个人研究笔记目录。线上入口：<https://lsyhahaha.github.io/notes/>。

## 新增笔记

1. 在本目录新增语义化 HTML 文件，文件名使用小写英文和连字符。
2. 复用 `notes.css`，不要为单篇文章复制整套样式或引入第三方运行时依赖。
3. 在 `index.html` 增加笔记卡片，并同步更新根目录 `sitemap.xml`。
4. 明确标注证据类型：官方材料、公开源码分析、个人推论或尚未验证。
5. 外部结论链接到原始来源，不把厂商案例直接表述为普遍事实。
